# 💰 Invoice / Faktur Tagihan

> **Fase:** Pembayaran
> **Tujuan:** Template invoice untuk ditagihkan ke client
> **Format:** Bisa diisi di Google Docs / Excel, atau langsung kirim PDF

---

## TEMPLATE INVOICE

```
[Logo Kamu]

[NAMA PERUSAHAAN / NAMA KAMU]
[Alamat]
[No. Telepon / WA]
[Email]

========================================
              INVOICE
========================================

Nomor Invoice    : INV-[Tahun]-[No Urut]
Tanggal Invoice  : [Tanggal]
Jatuh Tempo      : [Tanggal] (14 hari)
Project          : [Nama Project]
Klien            : [Nama / Perusahaan Client]

----------------------------------------

RINCIAN BIAYA

| No | Deskripsi | Jumlah |
|----|-----------|--------|
| 1  | [Termin/Item] | Rp .. |
| 2  | [Termin/Item] | Rp .. |
|    | **Total** | **Rp ..** |

Terbilang: #[Terbilang Rupiah]#

----------------------------------------

PEMBAYARAN

Bank       : [Nama Bank]
No. Rekening : [Nomor Rekening]
Atas Nama  : [Nama Pemilik Rekening]

Metode lain: [QRIS / GoPay / dll]

----------------------------------------

STATUS PEMBAYARAN

[ ] Belum Dibayar
[ ] Sudah Dibayar — [Tanggal]
[ ] Jatuh Tempo — [Tanggal]

----------------------------------------

Terima kasih atas kepercayaan Anda.

Hormat kami,

[Nama Kamu / Perusahaan]
```

---

## Contoh Nomor Invoice

- INV-2026-001 — Project A, DP
- INV-2026-002 — Project A, Termin 2
- INV-2026-003 — Project A, Pelunasan
- INV-2026-004 — Project B, DP

## Tips

- Kirim invoice ke email client + backup WhatsApp
- Cantumkan nomor invoice di subject/body pesan
- Simpan semua invoice untuk laporan pajak (jika sudah NPWP)
