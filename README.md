# 📁 Legal & Operational Documents — Freelance Web Project

Template dokumen standar untuk project freelance pembuatan website/aplikasi.
Semua dalam Bahasa Indonesia, format Markdown (.md) — tinggal isi & convert ke PDF/docx kalo perlu.

---

## 📋 Daftar Lengkap

| # | Dokumen | Fase | Fungsi |
|---|---------|------|--------|
| 01 | [Project Brief](01-project-brief.md) | **Discovery** | Intake form — gali kebutuhan client sebelum proposal |
| 02 | [Proposal & Quotation](02-proposal.md) | **Penawaran** | Proposal formal + rincian biaya |
| 03 | [NDA](03-nda.md) | **Kerahasiaan** | Perjanjian kerahasiaan (opsional) |
| 04 | [SPK](04-spk.md) | **Kontrak** | Surat Perjanjian Kerja utama |
| 05 | [SOW](05-sow.md) | **Teknis** | Statement of Work — lampiran detail teknis |
| 06 | [Change Order](06-change-order.md) | **Perubahan** | Form amandemen perubahan scope |
| 07 | [Progress & Meeting Notes](07-progress-report.md) | **Progress** | Laporan progress + notulen rapat |
| 08 | [BAST & UAT](08-bast-uat.md) | **Serah Terima** | Berita Acara Serah Terima + User Acceptance Test |
| 09 | [Invoice](09-invoice.md) | **Pembayaran** | Template invoice tagihan |
| 10 | [Maintenance Agreement](10-maintenance.md) | **Purna Jual** | Perjanjian maintenance & support bulanan |

---

## 🔄 Workflow Lengkap

```
Client Chat → [01-Project Brief] → Diskusi & klarifikasi
                  ↓
            [02-Proposal] → Kirim ke client
                  ↓
            [03-NDA] (jika perlu)
                  ↓
            [04-SPK] + [05-SOW] → Teken kedua pihak
                  ↓
              🚀 PROJECT START
                  ↓
            [06-Change Order] (saat ada perubahan scope)
                  ↓
            [07-Progress Report] (tiap milestone/weekly)
                  ↓
              ✅ PROJECT DONE
                  ↓
            [08-BAST & UAT] → Client sign-off
                  ↓
            [09-Invoice] → Kirim tagihan final + (10 jika ada)
```

---

## 🛠 Cara Pakai

1. **Copy** file `.md` yang dibutuhkan
2. **Isi** bagian yang `[dalam kurung siku]`
3. **Convert** ke PDF/docx kalo perlu (pake pandoc / Google Docs)
4. **Simpan** dokumen yang sudah diisi di folder per-client:
   ```
   clients/[nama-client]/docs/
   ```

---

## 📌 Catatan

- Semua template ini **bukan konsultasi hukum**. Untuk project bernilai besar (50jt+), sebaiknya konsultasi dengan notaris/legal.
- Template bisa dimodifikasi sesuai kebutuhan.
- Simpan dokumen asli yang sudah ditandatangani dengan baik.
